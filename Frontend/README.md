# Perfect CV Frontend

## Environment Variables

Create a `.env` or `.env.local` file in the frontend directory with the following variables:

```
VITE_URL="https://backend.perfectcv.mlsctiet.com"
```

This sets the backend API URL for the application. The default fallback URL is also set to "https://backend.perfectcv.mlsctiet.com" if the environment variable is not found.

## Development

To run the development server:

```
npm run dev
```
